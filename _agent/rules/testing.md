# 테스트

## 도구와 위치

| 도구 | 대상 | 위치 |
| --- | --- | --- |
| vitest | 함수와 모듈 단위. 커버리지 100% | `src/**/*.test.ts` |

## 원칙

- **테스트 없이 프로덕션 코드를 먼저 쓰지 않는다.** 모든 모듈이 vitest 테스트를 먼저 쓰고 Red → Green → Refactor로 간다.
- 실패를 먼저 본다. 통과시키는 가장 단순한 코드를 만든다. 통과한 테스트를 안전망 삼아 리팩터링한다.
- **커버리지 100%를 지향한다.** 테스트되지 않은 코드는 완성된 코드가 아니다. Statements·Branches·Functions·Lines 모두 100%여야 통과다. 줄(Lines)만 지나가고 분기(Branches)가 남은 상태는 100%가 아니다. 임계값은 네 항목 모두 설정 파일에 100으로 적고, 낮추거나 파일을 측정에서 빼서 통과시키지 않는다.

## 완료 전 검사

```bash
pnpm tsc --noEmit && pnpm lint && pnpm test:coverage
```

순서대로 실행한다.

1. `pnpm tsc --noEmit` — 타입 오류가 없어야 한다.
2. `pnpm lint` — 정적 분석을 통과해야 한다.
3. `pnpm test:coverage` — 테스트가 전부 통과하고 커버리지가 100%여야 한다.

실패하면 원인을 읽고 고친 뒤 처음부터 다시 실행한다. 고칠 수 없는 것은 항목과 사유를 보고한다.
