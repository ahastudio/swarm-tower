# 생존 시간과 게임 오버

## Background

이 게임의 결과는 얼마나 오래 버텼는가, 곧 생존 시간이다. 그래서 생존 시간이 화면에서 가장 먼저 보여야 하고, 적이 본부에 닿아 체력이 0이 되면 졌다는 것과 얼마나 버텼는지가 분명히 보여야 한다.

## Goal

게임은 생존 시간을 보는 게임입니다. 시간은 화면 왼쪽 위에 가장 먼저 보이고, 본부 체력이 0이 되면 게임이 멈추고 「게임 오버」와 생존 시간, 버틴 웨이브가 보이며, 다시 시작을 누를 때까지 그대로 남습니다.

## How it works

### 생존 시간

- 게임이 시작된 뒤 흐른 시간이 「생존 시간 분:초」로 보입니다(예: 「생존 시간 2:05」). 왼쪽 위에서 가장 먼저 보이고, 웨이브 표시는 그 아래입니다.
- 쉬는 시간도 생존 시간에 들어갑니다. 게임 오버가 되면 멈추고, 다시 시작하면 0:00으로 돌아갑니다.

### 본부 체력

- 본부 체력은 100이고 레벨이 올라도 같습니다. 적이 본부 중심에서 70 이내에 닿으면 1 줄고 그 적은 사라집니다.
- 집 아래에 체력 막대가 보입니다.

### 게임 오버와 다시 시작

- 체력이 0이 되면 갱신을 멈추고 「게임 오버」, 큰 글자의 「생존 시간 분:초」, 「웨이브 N까지 버텼습니다」, 「다시 시작」 버튼이 보입니다. 다시 시작을 누르기 전에는 그대로 남습니다.
- 버튼, Enter, 스페이스로 다시 시작하면 처음 상태(동전 0, 본부 레벨 1, 생존 시간 0:00)로 돌아갑니다.
