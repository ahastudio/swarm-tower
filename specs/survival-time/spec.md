# Feature Specification: 생존 시간과 게임 오버

## Overview

게임은 생존 시간을 보는 게임입니다. 시간은 화면 왼쪽 위에 가장 먼저 보이고, 본부 체력이 0이 되면 게임이 멈추고 「게임 오버」와 생존 시간, 버틴 웨이브가 보이며, 다시 시작을 누를 때까지 그대로 남습니다.

## User Scenarios & Testing (mandatory)

### User Story 1: 생존 시간 보기

- As: 플레이어는
- I: 게임 중에 지금까지 버틴 시간을 가장 먼저 볼 수 있다
- So: 얼마나 오래 버텼는지가 이 게임의 결과이기 때문에

#### Acceptance Scenarios

Scenario 1: **게임 중**

- Given: 게임이 시작되었을 때
- When: 화면을 보면
- Then: 왼쪽 위에 「생존 시간 0:00」이 가장 먼저 보이고 시간이 오른다

Scenario 2: **웨이브 표시와의 순서**

- Given: 게임 중일 때
- When: 왼쪽 위를 보면
- Then: 생존 시간 아래에 웨이브 표시가 보인다

### User Story 2: 게임 오버

- As: 플레이어는
- I: 본부가 부서지면 게임 오버와 생존 시간을 볼 수 있다
- So: 얼마나 버텼는지를 분명히 알기 위해

#### Acceptance Scenarios

Scenario 1: **게임 오버**

- Given: 본부 체력이 0이 되었을 때
- When: 화면을 보면
- Then: 게임이 멈추고 「게임 오버」, 큰 글자의 「생존 시간 분:초」, 버틴 웨이브, 다시 시작 버튼이 보인다

Scenario 2: **누르기 전까지**

- Given: 게임 오버 화면에서
- When: 다시 시작을 누르지 않고 기다리면
- Then: 생존 시간이 그대로 보인다

Scenario 3: **다시 시작**

- Given: 게임 오버 화면에서
- When: 버튼을 누르거나 Enter, 스페이스를 누르면
- Then: 처음부터 다시 시작하고 생존 시간은 0:00이다

## Functional Requirements (mandatory)

- FR-1: MUST 게임이 시작된 뒤 흐른 시간을 「생존 시간 분:초」로 화면 왼쪽 위에 가장 먼저 보인다.
- FR-2: MUST 웨이브 표시는 생존 시간 아래에 둔다.
- FR-3: MUST 본부 체력이 0이 되면 게임이 멈추고 게임 오버를 띄운다.
- FR-4: MUST 게임 오버 화면에 생존 시간을 가장 크게 보이고 버틴 웨이브 수와 다시 시작 버튼도 보인다. 생존 시간은 다시 시작을 누를 때까지 그대로다.
- FR-5: MUST 버튼, Enter, 스페이스로 다시 시작하고 생존 시간은 0:00으로 돌아간다.
- FR-6: MUST 본부 체력 막대가 보인다.

## Constraints (mandatory)

- CON-1: MUST 본부 체력은 100이고 적이 닿을 때마다 1 준다.
- CON-2: MUST 생존 시간은 게임이 도는 동안만 늘고, 게임 오버가 되면 멈춘다.

## Success Criteria (mandatory)

- SC-1: 체력을 0으로 만들면 게임 오버가 뜨고 갱신이 멈춘다(테스트).
- SC-2: 생존 시간이 분:초로 보이고, 게임 오버 화면에서 3초가 지나도 그대로이며, 다시 시작하면 0:00이다(테스트, 화면).
- SC-3: 버튼, Enter, 스페이스로 다시 시작한다(테스트).
