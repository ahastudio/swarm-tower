## Requirements

- MUST 생존 시간을 「생존 시간 분:초」로 왼쪽 위에 가장 먼저 보인다.
- MUST 게임 오버 화면의 생존 시간은 다시 시작을 누를 때까지 그대로다.
- MUST 본부 체력이 0이 되면 게임이 멈추고 게임 오버를 띄운다.
- MUST 버틴 웨이브 수와 다시 시작 버튼이 보인다.
- MUST 버튼, Enter, 스페이스로 다시 시작한다.
- MUST 본부 체력 막대가 보인다.

## Research Findings

### 코드베이스 구조

- `src/ui`: 화면 글(생존 시간, 동전, 웨이브, 로딩, 게임 오버, fps)
- `src/sim`: 갱신(주인공, 웨이브, 적, 전투, 타워, 동전, 본부)
- `src`: 시작과 게임 루프, 숫자 설정
- `index.html`: 전체 화면 캔버스와 글 요소

### 기존 패턴

- 한 프레임은 `update`(상태 갱신) 다음 `draw`(그리기) 순서로 돈다.
- 서 있는 물체는 `add*`가 `scene`에 더하고 발 위치로 앞뒤를 정렬해 그린다.

### 생존 시간

- 게임 시간(`game.time`)은 갱신마다 더해지고 게임 오버가 되면 갱신이 멈추므로 그대로 생존 시간이다. 처음 상태로 되돌리면 0이 된다.

## Technical Decisions

| Decision                                    | Rationale                                                                             |
| ------------------------------------------- | ------------------------------------------------------------------------------------- |
| 결과는 생존 시간이다                        | 이 게임은 얼마나 오래 버텼는지를 본다.                                                |
| 생존 시간이 화면에서 가장 먼저 보인다       | 가장 중요한 값이 가장 먼저 눈에 들어와야 한다.                                        |
| 생존 시간은 `game.time`을 그대로 쓴다       | 별도 시계를 두면 게임 시간과 어긋날 수 있다. 게임 오버에서 갱신이 멈추면 같이 멈춘다. |
| 분:초로 쓴다                                | 길어져도 한눈에 읽힌다. 한 시간이 넘으면 분이 계속 오른다.                            |
| 게임 오버에서 생존 시간을 가장 크게 보인다  | 결과를 먼저 알리고 웨이브는 보조로 둔다.                                              |
| 체력 0에서 게임을 멈추고 게임 오버를 띄운다 | 졌다는 것을 분명히 알리고 다시 시도하게 한다.                                         |
| 본부 체력 100, 닿을 때마다 1                | 본부 체력은 100이고 적이 닿을 때마다 1 준다.                                          |

## Learnings

### 생존 시간은 게임 시간으로 센다 (2026-11-25)

실제 시계가 아니라 게임이 돈 시간(갱신마다 더한 값)으로 세면 게임 오버 뒤에 자연스럽게 멈추고, 프레임이 늦어져도 게임 안의 시간과 같다.
