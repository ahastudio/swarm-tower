# 주인공 이동과 자동 공격

## Background

주인공은 플레이어가 직접 움직이는 유일한 캐릭터이고 전투도 맡는다. 공격은 자동으로 해서 플레이어는 이동에만 집중한다.

적이 큰 무리로 몰려오므로 한 마리씩 맞히는 방식이 아니라 폭발이 있는 원거리 포물선 탄으로 무리를 쓸어 낸다.

## Goal

주인공이 조작에 따라 걷고, 멈추지 않고 가장 가까운 적을 포물선 탄으로 자동으로 쏩니다. 본부 레벨이 오를수록 세집니다.

## How it works

### 이동

- 시작할 때 주인공은 본부 마당 문 바로 앞(2220, 1670)에 섭니다. 다시 시작해도 같습니다.
- 왼쪽 누르기와 끌기(마우스, 터치) 또는 WASD로 움직입니다. 화면 기준으로 걷고 초당 190의 속도입니다.
- 동작은 대기, 걷기(6프레임), 치기(5프레임)입니다.

### 자동 공격

- 쏘는 간격이 지나면 사거리 안의 모든 적을 훑어 가장 가까운 적을 고르고, 적의 속도로 앞을 겨눈 포물선 탄을 쏩니다.
- 탄은 0.32초 뒤에 터지고 폭발 안의 적 체력이 피해만큼 깎입니다.
- 본부 레벨 1의 값: 사거리 320, 0.35초마다, 폭발 반지름 40, 피해 1.

### 본부 레벨에 따른 강화

- 피해는 레벨 1~5가 1, 2, 2, 3, 4입니다.
- 폭발 반지름은 레벨마다 +6, 쏘는 간격은 0.92배, 사거리는 +25입니다.
