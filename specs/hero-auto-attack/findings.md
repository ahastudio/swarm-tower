# Findings & Decisions

> **기술적 발견, 중요한 결정이 있을 때마다 이 파일을 즉시 업데이트하세요.**

## Requirements

- MUST 주인공은 멈추지 않고 자동으로 계속 공격한다.
- MUST 공격은 원거리 포물선 탄이다.
- MUST 사거리 안에서 무조건 가장 가까운 적부터 공격한다.
- MUST 본부 레벨이 오르면 피해, 폭발 범위, 쏘는 속도, 사거리가 늘어난다.
- MUST 적의 속도로 앞을 겨눈다.
- MUST 주인공을 왕으로 만들지 않고 이름과 설정을 만들지 않는다.
- MUST 시작할 때 주인공은 본부 마당 문 바로 앞(2220, 1670)에 선다.

## Research Findings

### 코드베이스 구조

- `src/sim`: 갱신(주인공, 웨이브, 적, 전투, 타워, 동전, 본부)
- `src`: 시작과 게임 루프, 숫자 설정
- `src/render`: 그리기(바닥, 서 있는 물체, 연출, 알림)

### 기존 패턴

- 한 프레임은 `update`(상태 갱신) 다음 `draw`(그리기) 순서로 돈다.
- 서 있는 물체는 `add*`가 `scene`에 더하고 발 위치로 앞뒤를 정렬해 그린다.

### 조준

- 적의 속도로 앞을 겨눈다. 탄은 포물선이고 날아가는 시간 뒤에 폭발한다.

## Technical Decisions

| Decision                                                                      | Rationale                                                                         |
| ----------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 조작은 이동만 하고 공격은 자동이다                                            | 조작을 이동에 집중시키고 마우스, 키보드, 터치 어디서나 같은 전투 경험을 준다.     |
| 공격은 원거리 포물선 탄이다                                                   | 가까이 붙지 않고 무리를 폭발로 쓸어 낸다. 적의 속도로 앞을 겨눠 맞히기 쉽게 한다. |
| 가장 가까운 적부터 공격한다                                                   | 플레이어가 예측할 수 있고 본부 가까이 온 적을 먼저 막는다.                        |
| 본부 레벨이 오르면 피해, 폭발 범위, 쏘는 속도, 사거리가 늘어난다              | 본부 레벨 업이 성장의 중심이라 레벨 업의 보상이 분명하다.                         |
| 시작 위치는 마당 문 바로 앞(2220, 1670)                                       | 시작 화면에 본부, 울타리 문, 첫 타워 판 세 곳이 한눈에 들어온다.                  |
| 피해 1, 2, 2, 3, 4와 폭발 +6, 간격 0.92배, 사거리 +25, 레벨 1의 사거리 320 등 | 본부 레벨이 오를 때마다 위 값만큼 세진다.                                         |
