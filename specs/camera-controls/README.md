# 카메라 조작

## Background

위에서 내려다보는 화면을 휠 줌, 오른쪽 버튼 회전과 높낮이, 가운데 버튼 옮기기, 두 손가락 터치로 바꿀 수 있어야 한다. 카메라를 낮추면 층 한 장은 위아래로 좁아지고 층 사이 간격은 늘어야 입체가 끊기지 않는다. 카메라 중심은 주인공 머리다.

## Goal

휠 줌, 오른쪽 버튼 회전과 높낮이, 가운데 버튼 옮기기, 두 손가락 터치가 되고, 카메라를 낮춰도 층이 끊기지 않습니다.

## How it works

### 조작

- 휠: 줌 인, 줌 아웃(0.35~3배).
- 오른쪽 버튼 끌기 좌우: 회전. 위아래: 카메라 높낮이(`tilt` 0.35~1).
- 가운데 버튼 끌기: 화면 옮기기. 왼쪽 누르기와 끌기는 이동, WASD는 화면 기준 이동입니다.
- 카메라는 주인공을 부드럽게 따라갑니다. 카메라 중심은 주인공 발이 아니라 머리입니다.
- 시작할 때(그리고 다시 시작할 때) 카메라는 회전 0.6라디안, 높낮이 0.68, 줌 1입니다.

### 터치(두 손가락)

- 한 손가락은 지금처럼 탭하면 그곳으로 이동합니다. 두 번째 손가락이 닿으면 이동 목표를 지우고 카메라 조작만 합니다.
- 두 손가락을 벌리고 오므리면 줌 인, 줌 아웃입니다(두 손가락 사이 거리의 비율을 줌에 곱함). 두 손가락을 비틀면 회전입니다(잇는 선의 각도 변화를 회전에 더함).
- 두 손가락을 함께 위아래로 밀면 카메라 높낮이입니다(위로 밀면 낮아짐, 마우스의 오른쪽 끌기와 같은 방향).
- 두 손가락이 12px 움직이면 거리, 비틂, 위아래 중 가장 크게 움직인 쪽을 정합니다. 위아래이면 높낮이만, 아니면 줌과 회전만 움직이고 손가락을 뗄 때까지 유지합니다. 손가락이 하나 남으면 카메라는 움직이지 않습니다.

### 낮은 카메라

- 카메라를 낮추면 층 한 장은 `tilt`배로 위아래가 좁아지고, 층 사이 간격은 `1 + (1 - tilt)`배로 벌어집니다.
- 층은 가로 한 칸당 4장이라 tilt 0.35까지 내려도 층 사이가 비지 않습니다.
- 바닥에 놓인 그림자와 발밑 링의 세로 비율도 tilt를 따라 눌립니다.
