# Feature Specification: 카메라 조작

## Overview

휠 줌, 오른쪽 버튼 회전과 높낮이, 가운데 버튼 옮기기, 두 손가락 터치가 되고, 카메라를 낮춰도 층이 끊기지 않습니다.

## User Scenarios & Testing (mandatory)

### User Story 1: 카메라 조작

- As: 플레이어는
- I: 휠로 줌하고 오른쪽 버튼으로 회전하고 위아래로 높낮이를 바꿀 수 있다
- So: 원하는 각도에서 전장을 보기 위해

#### Acceptance Scenarios

Scenario 1: **줌**

- Given: 게임이 실행 중일 때
- When: 휠을 돌리면
- Then: 줌이 0.35~3배 안에서 바뀐다

Scenario 2: **회전과 높낮이**

- Given: 게임이 실행 중일 때
- When: 오른쪽 버튼을 누르고 좌우로 끌면
- Then: 회전하고, 위아래로 끌면 높낮이가 0.35~1 안에서 바뀐다

### User Story 2: 두 손가락 터치

- As: 모바일 플레이어는
- I: 두 손가락으로 줌, 회전, 높낮이를 바꿀 수 있다
- So: 마우스 없이도 전장을 원하는 각도에서 보기 위해

#### Acceptance Scenarios

Scenario 1: **줌**

- Given: 터치 화면에서
- When: 두 손가락을 벌리고 오므리면
- Then: 줌 인, 줌 아웃이 된다

Scenario 2: **회전**

- Given: 터치 화면에서
- When: 두 손가락을 비틀면
- Then: 비튼 만큼 회전한다

Scenario 3: **높낮이**

- Given: 터치 화면에서
- When: 두 손가락을 함께 위아래로 밀면
- Then: 카메라 높낮이가 바뀐다

Scenario 4: **이동과 구분**

- Given: 한 손가락으로 탭해 이동 중일 때
- When: 두 번째 손가락이 닿으면
- Then: 이동 목표가 지워지고 카메라 조작만 한다

### User Story 3: 낮은 카메라

- As: 플레이어는
- I: 카메라를 낮춰도 층이 끊기지 않는 입체를 볼 수 있다
- So: 높낮이를 바꾸는 재미를 위해

#### Acceptance Scenarios

Scenario 1: **층 간격**

- Given: 카메라를 tilt 0.35까지 낮췄을 때
- When: 물체를 보면
- Then: 층 사이에 빈틈이 보이지 않고 층 한 장은 위아래로 좁아져 있다

## Functional Requirements (mandatory)

- FR-1: MUST 휠로 줌 인, 줌 아웃을 한다.
- FR-2: MUST 오른쪽 버튼 끌기 좌우로 회전하고 위아래로 높낮이를 바꾼다.
- FR-3: MUST 카메라를 낮추면 층 한 장은 위아래로 좁아지고 층 간격은 늘어난다.
- FR-4: MUST 카메라 중심은 주인공 머리다.
- FR-5: MUST 바닥에 놓인 그림자와 링의 세로 비율은 카메라 높낮이를 따른다.
- FR-6: MUST 게임을 시작할 때와 다시 시작할 때 카메라는 회전 0.6, 높낮이 0.68, 줌 1이다.
- FR-7: MUST 두 손가락 터치로 줌, 회전, 높낮이를 한다. 지도 앱처럼 한다.
- FR-8: MUST 한 손가락은 탭 이동이고, 두 번째 손가락이 닿으면 이동 목표를 지운다.
- FR-9: MUST 두 손가락 조작은 줌과 회전 또는 높낮이 중 하나로 정해 손가락을 뗄 때까지 유지한다.

## Constraints (mandatory)

- CON-1: MUST 줌은 0.35~3배이다.
- CON-2: MUST 카메라 높낮이는 0.35~1이다. 층 사이가 비지 않는 한계에 맞춘 값이다.
- CON-3: MUST 시작 카메라는 회전 0.6, 높낮이 0.68, 줌 1이고, 두 손가락이 12px 움직이면 조작을 정하며 위아래 민감도는 1px당 0.003이다.
- CON-4: MUST 입력은 클릭(탭), WASD, 위의 카메라 조작이다.

## Success Criteria (mandatory)

- SC-1: 카메라 높낮이 0.35에서 층 사이가 비지 않는 것을 화면으로 확인한다.
- SC-2: 회전 방향과 끊김이 자연스럽다(화면).
- SC-3: 터치를 흉내 낸 테스트에서 벌리면 줌이 3배(한계)가 되고, 비틀면 회전이 따라가고, 위로 밀면 높낮이가 낮아진다.
- SC-4: 실제 터치 기기에서 손에 익는다(실제 기기에서 써 봄).
