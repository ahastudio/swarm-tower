# 개발자 정보 표시

## Background

개발하는 동안 성능을 눈으로 확인할 정보가 필요하다. 지금 보이는 정보는 fps이고 성능 목표는 60fps이다. 플레이어에게 필요한 정보가 아니므로 개발 서버에서만 보이고 배포판에는 넣지 않는다.

## Goal

개발 서버에서만 화면 왼쪽 아래에 개발자 정보(fps)가 0.5초마다 갱신되어 보이고, 배포판에는 나오지 않습니다. 성능 목표는 60fps입니다.

## How it works

### 개발자 정보

- 개발 서버(`pnpm dev`)에서 게임이 시작되면 왼쪽 아래에 「N fps」가 0.5초마다 갱신되어 보입니다. 프레임마다 개수를 세어 0.5초 동안의 평균을 냅니다.
- 배포판(`pnpm build`)에서는 요소가 숨겨져 있고 fps도 세지 않습니다. 번들에도 들어가지 않습니다.

### 성능 목표

- 성능 목표는 60fps입니다. GPU를 쓰는 Chromium 창에서 웨이브 1~20(적 52~884마리)을 돌린 화면 갱신은 폭 1280px와 390px 모두 59~61fps였고, 한 프레임의 JavaScript 시간은 0.6~3.8ms였습니다. 동전 약 2000개와 적 약 720마리가 함께 있는 가장 무거운 장면은 폭 1280px에서 57fps(JavaScript 18ms), 폭 390px에서 60fps(JavaScript 10ms)였습니다. 타워 없이 웨이브를 올린 가장 나쁜 경우이고, 소프트웨어 렌더링(헤드리스)은 폭 1280px에서 15~28fps로 느립니다.
