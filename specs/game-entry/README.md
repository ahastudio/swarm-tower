# 게임 진입

## Background

게임을 열자마자 불러오기부터 시작하면 플레이어가 준비되기 전에 무거운 읽기가 돌고, 처음 보이는 화면에서 아무것도 고를 수 없다. 타이틀 화면에서 시작을 누르게 하면 플레이어가 시작 시점을 정하고, 커뮤니티와 소스 코드 링크도 시작 전에 보여 줄 수 있다. 시작한 뒤에는 층 그림을 읽고 땅을 그리는 동안 화면이 비어 있으면 멈춘 것처럼 보이므로 진행 막대와 문구를 보인다. 문구는 읽는 대상을 가리키는 말이 아니라 「불러오는 중」 하나다.

## Goal

게임을 열면 타이틀 화면이 보이고, 시작 버튼을 누르면 로딩 화면을 거쳐 게임이 시작됩니다.

## How it works

### 타이틀 화면

- 게임을 열면 「Swarm Tower」 제목, 「시작」 버튼, 오른쪽 위의 「디스코드」와 「GitHub」 링크가 보입니다. 제목 글자는 하나씩 조금씩 늦게 위아래로 통통 튀고, 시작 버튼은 천천히 커졌다 작아집니다.
- 링크는 새 탭에서 열립니다. 디스코드는 `https://discord.gg/Y6kNcJvCwU`, GitHub는 `https://github.com/ahastudio/swarm-tower`입니다.
- 화면 폭이 360px인 세로 화면부터 1280px 이상의 가로 화면까지 잘리거나 겹치지 않습니다. 버튼과 링크의 터치 영역은 48px 이상입니다. 시스템에서 움직임 줄이기를 켜 두면 애니메이션이 멈춥니다.

### 시작

- 타이틀이 떠 있는 동안에는 층 그림을 읽지 않고, 게임 루프, 입력, 개발용 훅(`window.__game`)도 시작하지 않습니다.
- 시작을 누르면 타이틀이 사라지고 로딩 화면이 나옵니다.

### 로딩 화면

- 「Swarm Tower」 제목, 진행 막대(읽은 층 수에 맞춰 5%에서 90%까지 조금씩 오르고, 첫 화면까지 그리면 100%), 「불러오는 중」이 바다색 배경 위에 보입니다. 제목 글자는 타이틀과 같이 하나씩 늦게 통통 튀고, 「불러오는 중」은 숨 쉬듯 흐려졌다 진해집니다. 움직임 줄이기 설정에서는 멈춥니다.
- 층 그림 시트를 읽고 땅을 그리고 첫 화면을 그린 뒤 0.45초 동안 사라지고 화면에서 지워집니다.

### 게임 시작

- 로딩 화면이 사라지면 게임 루프가 돌기 시작하고 입력이 켜집니다. 개발용 훅(`window.__game`)은 개발 서버에서만 만들어지고 배포판에는 들어가지 않습니다.
