# 본부와 본부 레벨 업

## Background

본부는 성이 아니라 집 하나이고 레벨이 오르면 커진다. 처음에는 타워를 지을 곳이 3곳뿐이고, 모두 지으면 본부를 레벨 업해 타워를 지을 곳이 늘어난다. 이 순환이 성장의 구조다.

## Goal

본부 집이 레벨 5까지 커지고, 레벨이 오를 때마다 타워를 지을 곳이 세 곳씩 늘어나며, 레벨이 집 위에 보입니다.

## How it works

### 본부 집

- 본부는 섬 가운데(2200, 1400)의 집입니다. 벽, 지붕, 굴뚝, 배너, 등불 조각을 칸 단위로 이어 만든 층 그림입니다.
- 크기는 레벨 순서대로 2x1, 2x2, 3x2, 3x3, 4x3칸입니다. 집 위에 「레벨 N」이 노랗게 보입니다. 키울 때 집이 출렁입니다.

### 본부 레벨 올리기

- 열린 타워 곳을 모두 지으면 마당 안(본부에서 오른쪽 80, 아래 110)에 파란 「본부」 판이 나타납니다.
- 동전을 채우면 레벨이 오릅니다. 드는 동전은 60, 120, 200, 300입니다. 레벨이 오르면 마당이 넓어지고, 새 타워 곳 세 곳이 열리고, 「본부 레벨 N」 큰 글자가 보입니다.
- 타워 곳은 레벨마다 세 곳씩 모두 15곳입니다. 처음 세 곳은 아래쪽 문 앞입니다.
