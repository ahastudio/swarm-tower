## Requirements

- MUST 웨이브가 있고 플레이어가 알아볼 수 있다.
- MUST 적을 다 처치하지 않아도 다음 웨이브가 온다.
- MUST 웨이브 사이에는 새 적이 나오지 않는 쉬는 시간이 있다.
- MUST 웨이브 시작에 큰 글자를 보인다.
- SHOULD 화면 밖의 적이 있는 쪽을 화면 끝 화살표로 알린다.

## Research Findings

### 코드베이스 구조

- `src/sim`: 갱신(주인공, 웨이브, 적, 전투, 타워, 동전, 본부)
- `src`: 시작과 게임 루프, 숫자 설정
- `src/render`: 그리기(바닥, 서 있는 물체, 연출, 알림)
- `src/ui`: 화면 글(동전, 웨이브, 로딩, 게임 오버, fps)

### 기존 패턴

- 한 프레임은 `update`(상태 갱신) 다음 `draw`(그리기) 순서로 돈다.
- 서 있는 물체는 `add*`가 `scene`에 더하고 발 위치로 앞뒤를 정렬해 그린다.

### 웨이브

- 다음 웨이브는 한 웨이브의 적이 다 나온 뒤 쉬는 시간이 지나면 온다. 남은 적의 수와 쉬는 시간이 왼쪽 위 생존 시간 아래에 보인다.

## Technical Decisions

| Decision                                   | Rationale                                                      |
| ------------------------------------------ | -------------------------------------------------------------- |
| 적을 다 처치하지 않아도 다음 웨이브가 온다 | 남은 적을 잡을 때까지 멈추는 게임은 긴장이 끊긴다.             |
| 웨이브 사이에 쉬는 시간을 둔다             | 타워를 짓고 파워업할 시간이 필요하다.                          |
| 웨이브 n은 30 + 22n마리, 시작 전 5초       | 시작하고 5초 뒤에 웨이브 1이 오고 웨이브 n은 30 + 22n마리이다. |
| 큰 글자 2.4초, 화살표 12방향               | 알림이 화면을 오래 가리지 않으면서 방향을 알려 준다.           |

## Learnings

### 자동 플레이 테스트 (2026-11-25)

자동 플레이가 울타리 문을 거치지 못하면 난이도 테스트가 끝나지 못한다. 자동 플레이도 게임 규칙을 따라야 한다.
