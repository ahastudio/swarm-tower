# 웨이브와 쉬는 시간

## Background

웨이브는 시간으로 이어지는 압박이다. 플레이어는 지금 몇 번째 웨이브인지, 다음까지 얼마나 남았는지, 적이 어느 쪽에서 오는지 알아야 준비할 수 있다.

## Goal

웨이브가 시간으로 이어지고, 시작과 남은 시간, 남은 적, 화면 밖 적의 방향이 분명하게 보입니다.

## How it works

### 웨이브의 흐름

- 시작하고 5초 뒤에 웨이브 1이 옵니다. 웨이브 n은 30 + 22n마리이고 초당 (7 + 2n)마리씩 나옵니다.
- 한 웨이브의 적이 다 나오면 적이 남아 있어도 쉬는 시간(25초)을 거쳐 다음 웨이브가 옵니다. 쉬는 동안 새 적은 나오지 않습니다.

### 알림

- 웨이브가 시작될 때 큰 글자 「웨이브 N」이 2.4초 보입니다.
- 왼쪽 위 생존 시간 아래에 쉬는 동안은 「웨이브 N까지 M초」, 진행 중에는 「웨이브 N · 남은 적 M」이 보입니다.
- 화면 밖에 적이 있는 쪽은 화면 끝에 12방향 빨간 화살표가 보이고 적이 많을수록 진합니다.
