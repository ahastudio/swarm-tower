# 마당 울타리

## Background

처음에는 적이 본부에 쉽게 들어오지 못하도록 마당 울타리가 들어오는 곳을 문 하나로 제한한다. 울타리는 본부 둘레에만 있고, 본부 레벨이 오르면 마당이 조금씩 넓어진다. 적과 주인공 모두 울타리를 넘지 못한다.

## Goal

본부 마당 둘레에만 울타리가 있고 문은 아래쪽 하나이며, 적도 주인공도 울타리를 넘지 못하고, 본부 레벨이 오르면 마당이 넓어집니다.

## How it works

### 마당과 문

- 울타리는 본부 마당 다섯 선분뿐입니다(위, 왼쪽, 오른쪽, 아래 두 토막). 문은 아래쪽 가운데 하나입니다(본부 중심에서 좌우 50).
- 마당은 레벨 n일 때 x는 본부에서 좌우 165 + 60(n-1), 위는 180 + 40(n-1), 아래는 195 + 20(n-1)입니다.

### 울타리 그림

- 울타리는 층 그림 조각을 선분을 따라 37.4 간격으로 놓습니다. 조각의 양 끝 기둥 중심 사이가 37.4라 이웃 조각의 기둥이 하나로 겹치고 모든 변의 모양이 같습니다.

### 막는 방식

- 적의 흐름장은 울타리에서 21 이내의 칸을 막힌 칸으로 봅니다. 주인공은 울타리에서 16 이내로 가지 못하고 한 축만 미끄러집니다.
