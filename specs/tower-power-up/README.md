# 타워 파워업

## Background

타워도 파워업할 수 있어야 더 많이 짓는 것 말고도 선택이 생긴다. 타워 레벨은 본부 레벨을 넘지 못해, 본부 레벨 업이 성장의 중심이 된다.

## Goal

다 지은 타워 위에 서서 동전을 내면 타워가 강해지고, 타워 레벨은 본부 레벨을 넘지 못합니다.

## How it works

### 파워업

- 다 지은 타워 위에 서서 동전을 내면 타워 레벨이 오릅니다. 최고 레벨 5이고 드는 동전은 20, 40, 80, 160입니다. 돈은 판과 같은 속도(초당 40개)로 날아듭니다.
- 레벨마다 폭발 반지름 +10, 쏘는 간격 0.85배, 사거리 +30이 되고, 피해는 레벨 1~5가 1, 1, 2, 2, 3입니다.
- 타워 위의 노란 점이 레벨입니다.

### 본부 레벨 제한

- 타워 레벨은 본부 레벨을 넘지 못합니다. 모자라면 타워 가까이(170 이내)에서 「본부 레벨 N 필요」가 보입니다.
- 올릴 수 있으면 남은 동전(▲ 숫자)과 막대가 보입니다.
