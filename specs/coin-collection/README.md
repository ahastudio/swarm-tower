# 동전 떨어뜨리기와 줍기

## Background

적을 무찌르면 돈(동전)이 나오고 그 돈으로 짓는 것이 게임의 핵심 순환이다. 동전은 크고 분명해야 하며 앞뒤 그리기 순서가 맞아야 한다.

## Goal

적을 처치한 곳에 동전이 튀어 오르고, 주인공이 가까이 가면 빨려 들어와 오른쪽 위 동전 수가 오릅니다.

## How it works

### 동전

- 적을 처치한 곳에서 동전이 튀어 오릅니다(보통 적 1개, 센 적 3개, 아주 센 적 8개). 위로 170~250의 속도로 솟고 중력 640으로 떨어지며 바닥에서 한 번 튕깁니다. 돌고 반짝입니다.
- 서 있는 물체처럼 발 위치로 다른 물체와 함께 앞뒤를 정렬합니다. 한꺼번에 최대 2500개입니다.

### 줍기와 표시

- 주인공이 150 이내에 가면 동전이 빨려 들어오고 30 이내에서 얻습니다.
- 오른쪽 위에 동전 수가 보이고 동전을 얻으면 커졌다 돌아옵니다. 시작할 때 동전은 0입니다.
